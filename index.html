🚀 Launch Sequence

Deploy to Render in 4 Steps

From zero to a live WhatsApp bot in under 10 minutes — no credit card, no terminal, no pain.

1

Fork the Repository

Create your own copy of the bot on GitHub. Forking keeps the original repo untouched and gives Render a place to pull your code from. Make sure you're signed in to GitHub first.

Fork Knightbot-MD Fork KnightBot-Mini
2

Get Your Pair Code / Session

The bots connect to WhatsApp through a pair code — no QR scanning needed on Render. Open the official pair-code app, enter your WhatsApp number (with country code), and approve the prompt that appears on your phone's Linked Devices screen.

Open Pair Code App
Knightbot-MD
Download the generated creds.json and upload it into the session/ folder of your fork (session → Add file → Upload files → Commit).
KnightBot-Mini
Copy the session string that starts with KnightBot!H4... — you'll paste it as the SESSION_ID environment variable in Step 3.
3

Hit the Deploy Button

Click Deploy to Render on your chosen bot card above. Render opens a blueprint screen where you can review the service, name it, and — for KnightBot-Mini — paste your SESSION_ID session string into the environment variables before applying.

↑ Pick a Bot Card Deploy MD Deploy Mini
session / render.yaml — works for both bots 
# Drop this file at the root of your fork (name it render.yaml)
services:
  - type: web
    name: knightbot
    runtime: node
    plan: free
    region: oregon
    branch: main
    buildCommand: npm install
    startCommand: node index.js
    autoDeploy: false
    envVars:
      - key: SESSION_ID
        sync: false   # paste your KnightBot!H4… string (Mini)
      - key: NODE_ENV
        value: production
4

Go Live 🎉

Render builds and boots your bot (node index.js). Watch the logs — when you see the connection success line, send .menu or ,menu to your WhatsApp number and the command list drops. Keep the service on the Starter plan or higher for 24/7 uptime; free instances spin down after inactivity.

Knightbot-MD
Commands use the . prefix — try .menu, .tagall, .sticker, .tts.
KnightBot-Mini
Commands use the , prefix — try ,menu, then customize with ,setprefix, ,setname and more.

⚙️ Configuration

Environment Variables

Set these in Render under your service → Environment → Add environment variable.

Variable Bot Required What it does
SESSION_ID KnightBot-Mini Required Your pair-code session string starting with KnightBot!H4…. Without it, Mini boots into QR mode and cannot pair on Render.
creds.json Knightbot-MD Required Not an env var — upload this session file to the session/ folder of your fork after generating your pair code.
NODE_ENV Both Optional Set to production for cleaner, production-grade logging in Render logs.
Owner number Both Optional Edit settings.js (MD) or config.js (Mini) in your fork to set your WhatsApp number without + or spaces.
PUPPETEER_SKIP_DOWNLOAD KnightBot-Mini Optional Already set in code — keeps heavy Chromium downloads off your build and speeds up deploys.
